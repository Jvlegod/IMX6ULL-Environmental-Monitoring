# 设备监控与远程控制扩展规格

## 目标

完善服务端网页和 Qt 客户端, 支持遥测历史保存, 趋势查看, CSV 导出, 设备使能控制, 采样参数下发, 以及清晰可靠的 OTA 操作反馈.

## 功能范围

### 服务端数据

- 每条合法遥测写入 PostgreSQL, 保存设备 ID, 时间戳, 温度, 压力, 湿度, 光照和碰撞告警.
- 无数据库模式继续接收实时数据, 但历史查询和导出返回明确的不可用状态.
- 提供按设备和时间范围查询历史数据的 API.
- 提供同样筛选条件的 CSV 下载 API, 使用 UTF-8 和表头.

### 网页

- 设备列表显示在线状态, 当前遥测和设备使能状态.
- 趋势面板支持设备选择, 时间范围和四项主要指标折线图.
- 数据导出按钮下载当前筛选范围的 CSV.
- OTA 文件未选择, 上传中或任务创建中时按钮真正禁用, 失败后恢复并显示错误.
- 为每个设备提供使能/失能开关, 下发 `set_device_enabled` 命令并显示发送结果.

### Qt 客户端

- 将阈值, 采样时间, 采样周期和设备使能整理为统一分组布局.
- 接收 `set_device_enabled` 命令, 控制对应采集与遥测上传开关.
- 对无效参数返回错误, 对成功下发更新本地显示.
- 保持现有串口任务队列, 所有远程命令串行发送.

## 数据流

```text
传感器 → Qt 采集 → POST /api/v1/telemetry → PostgreSQL
网页 → 历史 API → 趋势图
网页 → CSV API → 下载文件
网页 → 命令 API → Qt 轮询 → 设备采集状态
```

## API 约定

- `GET /api/v1/devices/{device_id}/telemetry?from=&to=&limit=` 返回时间升序记录.
- `GET /api/v1/devices/{device_id}/telemetry.csv?from=&to=` 返回 `text/csv`.
- 设备命令沿用现有 `POST /api/v1/devices/{device_id}/commands`.
- 新命令格式为 `{ "kind": "set_device_enabled", "payload": { "enabled": true } }`.

## 错误处理

- 服务端校验时间范围, limit 和数值字段, 非法请求返回 400.
- 数据库不可用时实时设备 API 仍可工作, 历史接口返回 503 和可读错误.
- Qt 命令超时或设备拒绝时, 网页显示失败原因并允许重试.
- OTA 上传失败不保留半成品任务, 按钮恢复可用.

## 验证标准

- 连续发送遥测后, 历史 API 能返回相同记录.
- 网页趋势图能随时间范围变化更新.
- CSV 下载可被常见表格软件打开, 字段和筛选结果一致.
- 设备使能关闭后不再产生遥测, 重新使能后恢复.
- OTA 上传按钮在禁用状态不可触发请求.
- Qt ARM 构建和服务端测试通过.

## 分阶段实现

1. 服务端数据库迁移, 遥测历史 API 和 CSV 导出.
2. 网页趋势面板, 导出入口和 OTA 按钮状态.
3. Qt 设备使能命令和控件布局.
4. 端到端测试与部署说明.
